# 🏦 Central Bank Monetary Policy Simulator

A full-stack, interactive web-based simulator designed to mimic the monetary policy decisions of a Central Bank. This project integrates core macroeconomic principles with modern web development tools to visualize how interest rate adjustments impact inflation, economic growth, and public trust.

---

## 📊 Key Features & Economic Framework

*   **Monetary Policy Simulation:** Act as the Central Bank Governor to adjust the **Repo Rate** sequentially across multiple quarters.
*   **Macroeconomic Feedback Loop:** Simulates the real-world impact of rate cuts/hikes on **Inflation (CPI)**, **GDP Growth**, and **Unemployment** based on standard economic models.
*   **Dynamic Data Visualization:** Uses `Chart.js` on the frontend to plot live, multi-variable trend lines showing economic trajectories over time.
*   **Persistent Storage:** Uses an `SQLite3` database backend to log user decisions, quarterly parameters, and historical game states sequentially.

---

## 🛠️ Tech Stack Used

*   **Backend Framework:** Python (Flask)
*   **Database:** SQLite3 (SQL structured queries for state persistence)
*   **Frontend UI:** HTML5, CSS3 (Clean Dashboard layout)
*   **Data Visualization:** JavaScript (Chart.js library)
*   **Environment:** Built and tested entirely on a mobile micro-development setup (Pydroid 3).
